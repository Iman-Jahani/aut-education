# دفترچه اشتراکی کلاس پایتون — نسخه Next.js

بازنویسیِ حرفه‌ای‌ترِ پروژه‌ی قبلی (`index.html` + `class-23.html` + `admin-5.html`) با
**Next.js 14 (App Router) + TypeScript + Tailwind + Supabase**. همون دیتابیس Supabase
قبلی رو استفاده می‌کنه، پس داده‌های موجودت دست‌نخورده می‌مونه.

## اجرا

```bash
npm install
cp .env.local.example .env.local   # مقادیر پیش‌فرض همون قبلی‌هاست، لازم نیست چیزی تغییر بدی
npm run dev
```

سپس `http://localhost:3000` رو باز کن.

## ساختار پروژه

```
src/
  app/
    page.tsx              صفحه‌ی اصلی (لندینگ + پیوستن/ساخت کلاس)
    class/[code]/page.tsx  فضای کاری کلاس (سلول‌های کد، تیم‌ها، کامنت‌ها)
    admin/page.tsx          پنل مدیریت
    layout.tsx, globals.css
  components/
    ProfileModal, WelcomeModal, TeamPicker, CodeCell, CommentsPanel, ToastProvider
  context/
    AuthContext.tsx         ورود ناشناس Supabase + نام/آواتار کاربر
  lib/
    supabase.ts             کلاینت Supabase
    types.ts                تایپ‌های دیتابیس
    utils.ts                توابع کمکی (رنگ تیم، فرمت زمان، هش پین و ...)
    classJoin.ts             پیوستن به کلاس با کد (RPC به‌نام join_class_by_code)
    pyodide.ts               اجرای کد پایتون در مرورگر (Pyodide)
supabase/schema.sql          مستندِ ساختار جدول‌ها (برای مرجع)
supabase/join_class_by_code.sql   تابع RPCِ «پیوستن با کد کلاس» (لازم برای ورود به کلاس)
```

## چیزهایی که کامل پیاده‌سازی شده

- ورود خودکار (ناشناس) و پروفایل (اسم + آواتار)
- ساخت کلاس / پیوستن با کد کلاس / اشتراک لینک
- تیم‌ها: ساخت، پیوستن، خروج، لیست اعضا
- سلول‌های کد با CodeMirror، اجرای پایتون با Pyodide، ذخیره‌ی خودکار، حذف
- برچسب‌گذاری (تگ) روی سلول‌ها
- کامنت روی سلول‌ها
- به‌روزرسانی زنده‌ی سلول‌ها با Supabase Realtime
- حالت معلم (با رمز پین کلاس) برای دیدن همه‌ی سلول‌ها
- **تمرین‌ها**: ساخت/ویرایش/حذف توسط معلم (با چند تست‌کیس ورودی/خروجی)، حل توسط
  دانشجو با اجرای واقعی پایتون روی هر تست، نشان‌دادن نتیجه‌ی تک‌تک تست‌ها، بج
  تعداد تمرین‌های حل‌نشده، و صفحه‌ی «پاسخ‌ها» برای معلم با جزئیات کد هر دانشجو
- **کتابخانه‌ی تمرین‌های مشترک**: ذخیره‌ی تمرین در کتابخانه، جستجو و انتخاب از
  کتابخانه هنگام ساخت تمرین جدید، حذف از کتابخانه
- **کوییز زنده**: معلم سوال چندگزینه‌ای می‌سازه (با زمان محدود)، «شروع» می‌کنه؛
  همون لحظه یه بنر شناور با شمارش معکوس برای همه‌ی دانشجوها ظاهر می‌شه (Realtime).
  دانشجو پاسخ می‌ده (یا با اتمام زمان خودکار ارسال می‌شه)، نمره‌ش رو می‌بینه و
  می‌تونه پاسخ‌ها رو مرور کنه. معلم صفحه‌ی «نتایج زنده» داره: رتبه‌بندی زنده،
  میانگین نمرات، تعداد شرکت‌نکرده‌ها، و دکمه‌ی پایان کوییز.
- پنل مدیریت: آمار کلی، جدول کلاس‌ها، جدول تیم‌ها (با رمز عبور ساده مثل قبل)

## یک باگ که در همین مرحله درست شد

توی نسخه‌ی قبلی، وقتی آخرین خط سلول یه عبارت ساده بود (مثل `10 / 2`) و نتیجه‌ش
float بود، Pyodide موقع تبدیل نتیجه به عدد جاوااسکریپت، `.0` رو گم می‌کرد و
`5` نشون می‌داد نه `5.0`. حالا اجرای کد از طریق یه تابع کمکی پایتون (شبیه به
رفتار ژوپیتر/REPL) انجام می‌شه که `repr()` واقعی پایتون رو چاپ می‌کنه، پس
`5.0`, `'text'`, `[1, 2, 3]` و... دقیقاً مثل خود پایتون نمایش داده می‌شن.
(نکته: این یعنی `await` در سطح بالای یه سلول دیگه پشتیبانی نمی‌شه — که در یه
کلاس پایتون مقدماتی به‌ندرت لازم می‌شه.)

- **مسابقه‌ی تیمی**: معلم مسابقه (صورت سوال + زمان) می‌سازه و شروع می‌کنه؛ بنر شناور
  با شمارش معکوس برای همه ظاهر می‌شه. هر تیم یک پاسخ (کد) ارسال می‌کنه که برای
  همه‌ی اعضای تیم قابل‌مشاهده‌ست؛ با اتمام زمان، پیش‌نویس خودکار ارسال می‌شه. معلم
  پاسخ تیم‌ها رو زنده می‌بینه.
- **چت تیمی (جدید)**: هر تیم یه چت خصوصی و زنده داره (دکمه‌ی شناور 💬، بج پیام
  خوانده‌نشده، Enter برای ارسال). جدول `team_messages` لازمه — در `supabase/schema.sql` هست.
- همگام‌سازی زنده‌ی ویرایش هم‌تیمی‌ها روی سلول‌های مشترک تیم
- ظاهر جدید: هدر شیشه‌ای + ناوبری بخش‌ها، انیمیشن مودال‌ها، کارت‌های نرم، لندینگ کامل‌تر

- پیست و drag&drop در همه‌ی ادیتورها (سلول، تمرین، مسابقه) کاملاً غیرفعاله
- دکمه‌ی شناور «سلول جدید» + دکمه‌ی «＋» بین سلول‌ها برای درج در هر جایی؛ اسکرول نرم و هایلایت سلول جدید
- اسکلتون (skeleton) به‌جای متن «در حال بارگذاری» در همه‌ی بخش‌ها، و روی خروجی هنگام اجرای کد

- **input() داخل سلول‌ها**: وقتی برنامه ورودی بخواد، زیر خروجی یه فیلد ظاهر می‌شه (با متن prompt)؛
  جواب رو بنویس و Enter بزن. چون مرورگر نمی‌تونه وسط اجرا منتظر فیلد بمونه، سلول با جواب‌های
  جمع‌شده از اول «بازپخش» می‌شه (`random` با seed ثابت و متغیرهای سراسری بین بازپخش‌ها برگردونده می‌شن).
- **input() در تمرین‌ها**: متن prompt دیگه توی خروجی برنامه نمی‌آد و با خروجی مورد انتظار مقایسه نمی‌شه.
- خطاهای پایتون با traceback تمیز (بدون فریم‌های داخلی) نمایش داده می‌شن.

## قبل از اجرا: جدول‌های جدید Supabase

اگر جدول‌های `competitions`, `competition_submissions` و `team_messages` رو نداری،
محتوای `supabase/schema.sql` رو توی SQL Editor اجرا کن. برای چت و بنرهای فوری، Realtime
رو هم روشون فعال کن (خطوط کامنت‌شده‌ی انتهای فایل). بدون Realtime هم کار می‌کنه، فقط
با تأخیر ۱۰ تا ۱۵ ثانیه (polling).

## ایده‌های قدم بعدی

- رتبه‌بندی/امتیازدهی تیم‌ها در مسابقه توسط معلم
- تم تاریک
- ورود واقعی معلم با Supabase Auth به‌جای رمز کلاینتی

## نکات امنیتی (بدون تغییر نسبت به قبل)

- رمز پنل ادمین در `NEXT_PUBLIC_ADMIN_PASSWORD` است و سمت کلاینت چک می‌شه — دقیقاً
  مثل قبل، برای کلاس درسی کافیه ولی امنیت واقعی نیست.
- امنیت واقعی داده‌ها باید از طریق Row Level Security در Supabase تأمین بشه.
